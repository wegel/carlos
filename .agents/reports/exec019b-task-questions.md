# Native callback editors through the daemon

Commit `13e0ff1976fb05933d6478c75c6830b1941aaca5` adds the existing Codex and Claude question, form and browser-consent editors to the daemon terminal. This is the C2 task checkpoint within EP019b. The terminal and embedded wrapper share one borrowed card painter, field editor and caret. The terminal uses Client facts and typed commands; it creates neither SessionState nor BackendClient.

Each device keeps its own selected opaque card, field values, review page and confirmation. F4 leaves F2 or the goal panel through its normal close path without changing the daemon's approval focus or another terminal's editor. Older task selection survives. Answers preserve opaque field keys, native numeric versus string request identifiers, enum values, booleans, optional omissions and hidden secret review. Codex free text retains its trimmed `user_note:` prefix; Claude text stays unchanged. Neither path sends an answer as chat.

Approval facts now include a blocking flag, which defaults to true and omits true on the wire, plus an optional caller label. Core reuses the legacy pure caller formatter and clips display labels on a UTF-8 boundary with a visible ellipsis within 4096 bytes. The label carries no native routing payload. Readonly caller and browser-completion updates preserve private drafts and confirmations. Unsupported modes, missing schemas and invalid URLs remain read-only; decline and cancel stay available. The existing native URL limit remains 8192 bytes.

Callback writes require an accepted snapshot on the current connection and a Starting or Ready session. Ordinary sends still require Ready. A held, failed, stale or superseded subscription cannot authorize an answer merely because the client retained older Ready facts. An early key allocates no operation; the user must retry explicitly after the current subscription succeeds.

The typed `InterruptQuery` answer captures the original card and uses the existing guarded control worker and deadline. Codex keeps the original thread and turn. Claude uses its accepted public turn when present; otherwise it captures the original helper/card intent. The command never guesses a root, answers the question or publishes ApprovalAnswered. Native Decision(Cancel) remains distinct, while Codex question Alt+C retains its legacy query-interrupt behavior. A failure reopens only the same still-live claim, preserves the private draft and reports an uncertain outcome without retrying automatically.

Browser completion adds a readonly notice to the same card and grants no consent. Ctrl+Y copies the captured URL through the same clipboard permission, single worker and bounded queue used for source and selection copies. Duplicate own jobs fail clearly; stale copy replies cannot replace a newer job's status. No browser launcher was added because the previous terminal has none.
