Core's AI tool-label provider starts its current executable with the private __summary-reader command when the model asks to inspect source files. After the daemon split, that executable is carlosd. Its CLI rejected this command, although the terminal executable still supported it. This could leave labels without the source reads they requested.

The daemon now delegates that private command to the existing bounded reader before parsing server arguments. It uses the same read-only tools, workspace checks, audit and budgets.
