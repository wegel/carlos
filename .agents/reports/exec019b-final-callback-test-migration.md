# Final question and approval-lifetime test owners

The final move retires thirteen parent Codex question tests, their one parser test and nine approval-lifetime tests. The Core library owns native session facts and now checks requests and replies; Device, the actual terminal object, checks private input, focus and secret handling. The already-committed frozen native reply corpora, fixed-seed model and allocation tests remain unchanged. No terminal successor constructs SessionState or BackendClient, and no new native command exists.
