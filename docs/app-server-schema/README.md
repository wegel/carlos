# Codex app-server schemas

The current bundles were generated by `codex-cli 0.163.0` with:

```bash
codex app-server generate-json-schema --experimental --out docs/app-server-schema
```

Use `codex_app_server_protocol.schemas.json` and
`codex_app_server_protocol.v2.schemas.json` to check the current server's methods
and types. The generator leaves older per-method files in place, including the
rollback schemas Carlos uses when it talks to an older server. A method appears
in the current bundles only if the current server supports it.
